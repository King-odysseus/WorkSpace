# WorkSpace User Guide

This guide explains how to use WorkSpace, what each page is for, and the main
workflows for running a team workspace.

## 1. Getting started

### Sign in and sign up

- Open the WorkSpace URL.
- If you already have an account, enter your email and password and select **Sign in**.
- If this is your first visit, choose **Create an account**.
- Enter your first name, workspace name, email, and a password of at least 8 characters.
- After signing in, WorkSpace opens on **Today**.

### The app shell

- The left sidebar contains all main pages.
- On desktop, the sidebar can be expanded or collapsed into an icon rail.
- On mobile, the main destinations appear in a bottom pill navigation.
- The bottom pill includes a **More** button that opens the full navigation drawer.
- The top header shows the active page, global search, workspace switcher,
  notifications, theme toggle, Help, and your profile menu.

### Global search

- The search field in the header filters tasks across the current workspace.
- On smaller screens, use the search field inside the relevant page.

## 2. Today

Today is the daily launchpad. It shows what needs attention now.

### What you can do

- See the greeting, today date, and your workspace name.
- Use **Add task**, **Add event**, or **Check in** from the top actions.
- Review four metrics:
  - **Due today**
  - **Overdue**
  - **Blocked**
  - **Completed today**
- Use **My day** to see prioritized tasks assigned to you.
- Use the checkbox to complete a task.
- Change a task status directly from the row.
- Open a task title to see its full detail drawer.
- Review today's **Schedule**.
- Review due **Follow-ups**.
- Review **Team attention** exceptions.
- See today's **Check-ins**.

## 3. My tasks

My tasks is a focused queue of work assigned to you.

### Views

- **Inbox**: all open tasks assigned to you.
- **Today**: tasks due today.
- **Upcoming**: tasks due after today.
- **Overdue**: tasks whose due date has passed.
- **Blocked**: tasks currently blocked.
- **Completed**: tasks you have finished.

### Filters and sorting

- Filter by status, priority, project, and planner bucket.
- Sort by priority, due date, or recently completed.
- Search with the **Search my tasks** field.

### Task actions

- Complete or reopen a task with the round checkbox.
- Change status with the row dropdown.
- Open a task to edit it.
- Archive a task with the icon button, if you have permission.

## 4. Daily operations

Daily operations is for recurring and day-to-day work that is not linked to a
project.

### What belongs here

- Tasks with **Operations** scope.
- Recurring team work such as finance, customer support, people operations, or
  administrative routines.
- Operations workstreams.

### Workstreams

- Use the **Operations workstreams** form to create reusable lanes such as
  `Finance`, `Customer Support`, or `People`.
- After a workstream is created, you can filter tasks by it.

### Planning views

Use the same planning controls as Planner:

- **Board**: a kanban-style board grouped by buckets.
- **Table**: a compact task table with progress, owner, priority, target date,
  and status.
- **Gantt**: a timeline view of scheduled tasks.

### Buckets

- Create buckets with the **Add bucket** form.
- Drag tasks between buckets.
- Drag bucket headers left or right to reorder them.

### Filters

- Search tasks.
- Filter by status, workstream, priority, assignee, supporter, phase, bucket,
  due date, and date range.
- Use **More filters** to reveal the full filter set.
- Use **Clear filters** to reset.

## 5. Planner

Planner is project delivery work.

### Project scope

- The Planner is scoped to projects, not daily operations.
- Choose **All projects** or a specific project.

### Saved views

- Filter and search the Planner the way you want.
- Enter a name in **Save current filter as...** and select **Save view**.
- Load a saved view from the dropdown.
- Delete a saved view when it is no longer needed.

### Board, Table, and Gantt

- **Board** is the kanban view.
- **Table** shows task details and progress.
- **Gantt** shows scheduled tasks over time.

### Task movement

- Drag tasks between buckets.
- Reorder tasks and buckets when you have permission.
- Use the move controls on each task card as an accessible alternative to drag.

## 6. Team board

Team board shows ownership and workload across the workspace.

### Metrics

The top cards show:

- Open tasks
- Blocked tasks
- Overdue tasks
- Unassigned tasks

### Modes

- **People**: task workload grouped by teammate.
- **Status**: tasks grouped by current status.
- **Priority**: tasks grouped by priority.

### Scope

Use the scope selector to see:

- All work
- Operations only
- A specific project

### People and access

At the bottom of Team board, workspace leaders can:

- Invite members.
- Change a member's role.
- Remove a member.
- Cancel pending invitations.

## 7. Projects

Projects track larger initiatives, milestones, and delivery work.

### Create a project

- Select **New project**.
- Enter a project name, description, and optional due date.
- Save it.

### Edit or delete a project

- Use the project card controls if you are an owner or manager.
- Change project status between planning, active, paused, or completed.
- Delete a project only when you are sure, because it cannot be undone.

### Project health

Each project card shows:

- Completion percentage.
- Open, blocked, and overdue task counts.
- Health: on track, at risk, off track, or completed.

### Risk register and issue log

Inside a project, use the project controls to:

- Add risks or issues.
- Set severity.
- Assign an owner.
- Set a target date.
- Update status.
- Delete records.

## 8. Calendar

Calendar manages meetings, focus time, deadlines, and reminders.

### Add an event

- Select **Add event**.
- Enter title, description, start and end time, event type, and reminder.
- Save.

### Views

Choose from:

- Day
- Week
- Month
- Year
- Agenda

### Filters

Filter by:

- All events
- Meetings
- Focus time
- Deadlines
- Reminders

### Upcoming panel

- Review the next upcoming events.
- Export the workspace calendar as an ICS file.
- Add an event to Google Calendar.

## 9. Channels and Chats

Channels and Chats are the two communication spaces.

### Channels

- Use **Channels** for shared team topics.
- Open an existing channel from the sidebar list.
- Search messages inside a channel.
- Reply to messages.
- Create a channel with **Create channel**.
- Choose whether a channel is private.
- Delete a channel if you created it.

### Chats

- Use **Chats** for private one-to-one or group conversations.
- Start a direct chat with one person.
- Start a group chat with multiple people.
- Search messages inside the selected conversation.
- Send messages with **Enter**. Use `Shift+Enter` for a new line.

## 10. Follow-up

Follow-up tracks commitments that need a response or another action.

### Add a follow-up

- Select **Add follow-up**.
- Enter a note and due date.
- Optionally assign it to someone.
- Optionally link it to a task.

### Manage follow-ups

- Filter by all, open, completed, or overdue.
- Edit a follow-up if you created it, are assigned to it, or are a leader.
- Mark it done or reopen it.
- Delete a follow-up if you have permission.

## 11. Check-ins

Daily check-ins keep the team aligned.

### Start or edit a check-in

- Select **Start check-in**.
- Choose the date.
- Enter what you completed.
- Enter what is next.
- Enter any blockers.
- Save.

### Review check-ins

- Use **View date** to look at a different day.
- Check-in cards show the person, date, completed work, next steps, and blockers.
- If you own a check-in, use the icon on the card to edit it.

## 12. Reports

Reports summarize progress, workload, and delivery health.

### Scope

Use the scope selector to report on:

- All work
- Operations only
- A specific project

### Period

Choose:

- All time
- Last 7 days
- This month

### Metrics

Reports include:

- Total tasks
- Overdue tasks
- Blocked tasks
- Completion rate
- Check-ins today

### Drill through

- Select a status, overdue item, blocked item, or unassigned item to open the
  relevant Planner or Daily operations view with that filter applied.
- Use **Refresh reports** to reload data.

## 13. Activity

Activity shows a recent history of workspace changes.

- Search activity text.
- Filter by person.
- Filter by activity type.
- Refresh activity when needed.
- Activity is grouped by day.

## 14. Settings

Settings control your personal experience and workspace access.

### Appearance

- Choose **Light**, **Dark**, or **System** theme.
- Choose whether the desktop sidebar is expanded or collapsed.

### Notifications

Control these notification categories:

- Mentions
- Direct messages
- Task updates
- Calendar reminders

You can also enable desktop browser notifications.

### Profile

- Upload, replace, or remove your profile photo.
- Set your presence to Available, Busy, Away, or Offline.
- View your email address and workspace role.

### Workspace access

Workspace leaders can review:

- Total members.
- Number of managers.
- Your role.
- Member list.

Member invitations and role changes are available from Team board.

## 15. Help and Legal

### Help

- Open Help from the sidebar.
- Review quick explanations of core workflows.
- Use the shortcut buttons to open Today or Planner.

### Legal

- Open Legal from the sidebar.
- Review the privacy notice, cookie notice, terms of service, and acceptable use
  policy.
- Confirm your policy acknowledgement when required.

## 16. Common workflows

### Create and assign a task

1. Select **Add task** from Today, My tasks, Planner, or Daily operations.
2. Enter the task name.
3. Add a description.
4. Assign it to someone.
5. Choose a due date.
6. Choose a project or leave it in Operations.
7. Choose a priority.
8. Choose a planner bucket.
9. Select **Create task**.

### Run a daily operations routine

1. Open **Daily operations**.
2. Create or choose an operations workstream.
3. Add tasks with no project assigned.
4. Move tasks through board buckets.
5. Update status as work progresses.
6. Add blockers when something is stuck.

### Track a project

1. Open **Projects**.
2. Create or open a project.
3. Add project tasks from Planner.
4. Track progress on the project card.
5. Add risks and issues from the project detail view.

### Invite a teammate

1. Open **Team board**.
2. Select **Invite member**.
3. Enter their email and role.
4. Send the invitation.
5. The teammate accepts it from their invitation.

### Complete a daily check-in

1. Open **Check-ins**.
2. Select **Start check-in**.
3. Fill in completed work, next steps, and blockers.
4. Save.
5. Edit it later from your check-in card if needed.

## 17. Roles and permissions

- **Owner**: full workspace control, including member management.
- **Manager**: manages members and most workspace work.
- **Member**: completes tasks, joins conversations, sends check-ins, and manages
  their own items.

Some actions, such as inviting members or changing project ownership, are only
available to owners and managers.
